# Harbor 0.2 — 启动可见，操作可控

目标用户是在 Mac 上通过 Wine Steam 玩已有游戏的人。主界面的任务是选游戏、启动，并解释接下来在等什么，不是展示兼容性宣传页。

沿用 SwiftUI 原生应用、既有容器适配和独立帆船标识。不改成 WebView，不改写游戏或注入联机/反作弊进程。

## 设计选择

- 色彩：Harbor Blue `#3469EF`（主动作）、Signal Teal `#158C83`（有证据的完成）、Wait Amber `#B27A27`（等待较久）、Fault Red `#D7524A`（明确错误）、Graphite `#20252E`、Mist `#F2F4F8`。正文/背景仍以 macOS 语义色与材质适配深浅色。
- 字体：系统字体的圆角 Semibold 用于少量标题，默认系统 Regular 用于正文；等宽数字/系统 Mono 仅用于时间、容量和技术路径。
- 布局：保留原生侧栏与右侧检查器。缩小游戏封面和标题区，让启动状态在常用窗口尺寸中持续可见。高级配置折叠，主路径只显示选择、启动、状态。
- 核心识别元素：一条对应真实检查点的“启动轨道”。磁盘、环境、Steam、进程、窗口依次提供可核实反馈。它不是模拟耗时的百分比。

```
侧栏             游戏库 / 搜索                  游戏详情
游戏库           启动状态 + 已耗时 + 最近检查     启动 / 显示窗口
运行环境         [磁盘—环境—Steam—游戏—窗口]      所在磁盘
游戏预设         游戏封面网格                    图形设置（展开）
启动与任务       当前状态 / 收藏                 技术信息（展开）
```

自检：去掉原版的大段宣传式标题与重复免责声明；把腾出的空间用于可操作的状态。不要用大面积磨砂卡片、弹跳动画或假进度制造“Apple 风格”。原生材质只用于层级和当前任务，系统字体与留白负责主体。

## apple-design 的具体落实

- 点击后立即创建启动记录，耗时检查放到后台。按钮保留按下反馈，重复点击不重复派发启动。
- 0.3 秒、阻尼 1 的克制弹簧只用于状态面板/选择反馈；减少动态效果时退化为短淡入或静态。
- 尊重减少透明度和增强对比度。状态同时有文字、图标和颜色，不仅靠色点。
- 保持用户控制：“停止跟踪”不强杀已启动的软件。等待较久是提示，不等同于断言“卡死”。

## 进度证据边界

阶段条表示已确认的检查点数量，不估算启动总耗时。下载百分比只能来自 Steam 已写出的字节计数，并标明来源/更新时间。窗口出现只表示交给游戏，不保证主菜单、联网、VAC、帧率或实际游戏响应。

连接状态只解析 Steam 登录日志中的白名单事件，不读取账号配置，不保存 token、账号标识或原始连接日志。游戏内匹配和地图加载未提供通用外部信号，不能伪造其进度。

联机兼容性需要针对具体游戏和版本单独实测，不能从启动检查点推广到全部联网游戏，也不能冒充每次启动的自动验收。
