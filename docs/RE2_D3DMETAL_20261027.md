# Resident Evil 2 D3DMetal repair — 2026-10-27

## Cause and change

RE2 app 883710, installed public build 11636119, requested DirectX 12 and failed at `D3D12CreateDeviceFailed` (`renderdevicedx12.cpp:11796`). The linked environment used DXMT. During reproduction, `lsof` showed RE2 loading Wine's built-in `d3d12.dll` alongside DXMT's `dxgi.dll` and `d3d11.dll`.

The environment already contained D3DMetal, but Harbor's per-game renderer enum offered only inheritance, DXMT and DXVK. Editing the wrapper manually was ineffective because an authorized Harbor launch restores the saved baseline. Version 0.5.2 adds a D3DMetal preset, sets D3DMETAL=1 and DXVK=0, displays the effective renderer correctly, and preserves existing baseline restoration and stopped-session requirements.

Only RE2 was assigned the new preset. Other games retain their previous presets. Switching games with a different backend requires normally exiting Steam and its Wine session first. No game files, saves, disk mappings, or baseline backups were changed by the repair.

## Verification

- Two new regression tests first failed because D3DMetal was absent from the renderer enum.
- Full `swift test`: 66 tests, 0 failures, 1 skipped. The skipped test requires an explicitly designated disposable Wine runtime.
- Tests cover preset serialization, configuration application, restoring the complete original baseline, rejecting a switch during a running session, and rejecting DXMT-only options for D3DMetal.
- Release build and strict ad-hoc code-signature verification passed. Harbor 0.5.2 was installed locally, with the previous app and state snapshots retained.
- Native Harbor UI showed all ten games, exposed the D3DMetal option and saved it for RE2.
- The new Wine Steam process loaded the bundled D3DMetal framework, shared library and DXGI DLL. At this checkpoint, Steam required renewed login; RE2 gameplay validation remained pending.

This is a local preview, not a public or notarized release. Unit tests and DLL loading do not prove game playability.

## Rollback

The previous application is retained at `~/Applications/.Harbor-before-re2-0.5.1.app`. The matching pre-change state and original wrapper configuration are under `~/Library/Application Support/Harbor/ConfigurationBackups/RE2-D3D12-20261027-222522/`.

An old Harbor binary does not recognize the new `d3dmetal` serialized enum. Restore its matching state snapshot as well as the old application when rolling back, with Harbor and the Wine environment stopped. Do not restore an old state snapshot over newer unrelated user changes without reconciling them.
