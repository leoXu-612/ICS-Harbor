# ICS-Harbor 0.6.1 Preview · build 18

- 资料库采用萤石蓝：深色外观使用偏紫的蓝色高光，浅色外观使用钴蓝。侧栏和扫描提示浮层增加轻微透色，启用 macOS「减少透明度」时使用实色。主按钮与文字保持不透明，帆船图标同步更新。
- 相比上一公开版本 0.5.2，游戏和应用现在共用一张可搜索、排序和筛选的清单。手动改变游戏/应用分类不改变实际启动方式。
- Steam 和本地导入分别维护接入方式，Wine 环境单独维护引擎、占用和磁盘。Epic Games、GOG 仍为规划中的连接器。

## 安装与升级

Apple Silicon，macOS 14.6 或更新版本。运行当前 Wine 组件需要 Rosetta。正常退出游戏、Windows 程序、Steam 和 Wine 环境后退出 Harbor，再用 DMG 中的 Harbor.app 替换原安装位置。可在更新前备份 Harbor 的索引。开发预览使用 ad-hoc 签名，未经 Apple 公证。

## 验证

Release 构建、DMG 校验及挂载后的应用签名检查通过。使用隔离索引实测深浅色窗口和详情主按钮。99 项 Swift 测试中 96 项通过，3 项真实运行环境测试按默认设置跳过。DMG 未捆绑游戏、Steam 客户端或 Wine 引擎。
