# Harbor 0.6.0 Preview · build 17

第三套来源中心的信息结构，深海蓝灰表面、冰青强调色，并保留跟随系统的浅色外观。统一清单覆盖 Steam 清单和本地可执行程序；来源管理与运行环境维护分开。

自定义游戏/应用分类是可选索引元数据；本地记录使用原 UUID，Steam 条目使用原环境 ID 与 App ID。显示类型不决定启动路径。0.5 索引无需迁移。回退时应恢复对应索引备份；旧版保存状态时不会保留它不认识的分类字段。

验证：99 项 Swift 测试中 96 项通过，3 项依赖真实 Wine 环境的测试跳过，0 失败。本次以独立索引与测试目录运行应用，检查混合清单、游戏/程序详情、Steam 来源清单、接入维护、环境关联内容和规划平台提示。通过 UI 将本地记录改为游戏，重启最终包后确认分类仍在、本地来源不变，再恢复分类。没有启动游戏或安装器。Release 为 arm64、ad-hoc 签名；最终 DMG 已验证并挂载，应用签名通过严格验证。实机截图为本地验收证据，不随发行包分发。

Amicro 的 MIT snappy 弹簧参数已移植到来源标签切换，许可证与固定版本见 THIRD_PARTY_NOTICES.md。
