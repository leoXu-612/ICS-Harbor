# ICS-Harbor 验证范围

这是可提交到源码仓库的验证摘要，不包含本机账号、容器标识、游戏存档、原始日志或屏幕截图。

## 0.5.0 操作层级改版

验证日期：2026-10-27。保持原生 SwiftUI，导航分为资料库、管理和帮助；增加操作指南与按环境状态选择下一步的应用流程，折叠高级维护，并突出已有库冲突。

- 完整测试执行 62 项：61 项通过，1 项显式启用的真实 Wine 烟雾测试跳过，零失败；本轮未启动游戏或安装新 Windows 软件。
- 独立审查指出“仅有 system.reg 不等于准备完成”，补充失败回归后验证修复：安装指引和安装入口检查托管身份、准备标记、Win32 探测结果及必要程序文件，不修改索引 schema。
- 实机检查了浅色游戏详情、深色环境页、创建流程的取消路径、指南跳转和高级区展开/收起。修正宽屏游戏网格留白及重复冲突提示，恢复原先的跟随系统外观。
- 原容器 UUID、路径、应用入口、预设、收藏、绑定及 schema 与升级前备份逐字段一致；原容器 Info.plist 哈希不变。应用仍使用原 Bundle ID 和数据目录。
- Release 构建、签名和 ZIP 完整性检查通过。仍为未公证的本地预览；更新后 macOS 可能要求重新允许外置盘访问。
- 未完成全窗口尺寸矩阵、VoiceOver 完整认证或本轮游戏对局测试，不宣称设计奖认证或不存在任何主观改进空间。既有共用库冲突只提升显示优先级，没有自动修改库登记。

## 0.4.0 本地预览

验证日期：2026-10-15。平台：Apple Silicon、macOS 27.0、Swift 6.3.3。结果不自动推广到其他系统、机型或 Windows 软件。

- 独立创建不含 Steam 的 Wine 环境，固定组件哈希校验和 Win32 初始化通过。
- 从原生界面分别启动官方 7-Zip 26.04 x64 EXE 与 MSI 安装器，由测试者完成向导。两条路径均返回退出码 0，随后验证了已安装应用能实际启动。
- 导入已有 EXE、编辑显示名称及启动参数、保存后重启 Harbor，应用记录保持。带目录参数启动后，应用实际打开对应目录。
- 独立应用的“磁盘 → 环境 → 程序 → 窗口”检查点可到达 4/4，不依赖或伪造 Steam 连接状态。
- Noto Sans CJK SC 字体与该测试环境的字体替代配置解决了所测应用的中文菜单方框问题。
- 50 项测试通过：49 项核心及回归测试，1 项显式启用的真实 Wine 文件往返测试。后者使用生产命令生成逻辑，在含中文、空格、`&`、`%` 的临时路径内调用 Windows 7-Zip 压缩、解压，恢复文件逐字节一致。
- 原有 Steam 配置、游戏预设、收藏及绑定记录保持；该轮未重新验证游戏对局、反作弊或帧率。
- 本地 Release 应用和 ZIP 完整性验证通过。签名为 ad-hoc，未进行 Developer ID 签名、公证或公开二进制发行。

## 重复验证

```sh
swift test
```

普通测试不下载、安装或运行 Windows 程序；真实 Wine 测试默认跳过。仅在准备好专用临时托管环境、并安装可信的官方 7-Zip 后，显式运行：

```sh
HARBOR_SMOKE_WRAPPER=/absolute/test/Runtime.app swift test --filter StandaloneSmokeTests
```

测试会运行 Windows 7-Zip，创建并删除自己的临时测试文件。不要将日常使用的环境或未验证的可执行文件作为测试目标。

## 尚未验证

MATLAB、COMSOL、任意 Windows 驱动、全部 EXE/MSI 安装器、所有游戏和其他机器的兼容性均不在本次证明范围内。出现进程或窗口不等于应用核心功能、计算结果或长期稳定性通过。正式发布还需逐项完成第三方组件许可、目标机器与最低系统版本测试，以及签名、公证和升级验证。
